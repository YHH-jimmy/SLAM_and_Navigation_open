# KITTI to ROS2 Bag 轉換工具 - 快速入門

## 📋 簡介

這是一個完整的 KITTI 資料集轉 ROS2 bag 格式的轉換工具，完全相容 ROS2，支援所有感測器資料。

**主要功能:**
- ✅ IMU 高頻率數據
- ✅ GPS 位置與速度
- ✅ Velodyne LiDAR 點雲 (含 ring channel)
- ✅ 相機影像 (灰階/彩色, 左/右)
- ✅ TF 座標轉換
- ✅ 相容 LIO-SAM

## 🚀 快速開始

### 1. 安裝與編譯

```bash
cd ~/ros2_ws
colcon build --packages-select kitti2bag_ros2 --symlink-install
source install/setup.bash
```

### 2. 安裝依賴

```bash
pip install pykitti
```

### 3. 使用方式

#### 方法 A: 直接執行命令

```bash
# RAW Dataset (完整感測器)
python3 /home/jimmyrtioms/ros2_ws/install/kitti2bag_ros2/lib/kitti2bag_ros2/kitti2bag \
    raw_synced /path/to/kitti/raw -t 2011_09_26 -r 0001

# Odometry Dataset (灰階)
python3 /home/jimmyrtioms/ros2_ws/install/kitti2bag_ros2/lib/kitti2bag_ros2/kitti2bag \
    odom_gray /path/to/kitti/odometry -s 00

# Odometry Dataset (彩色)
python3 /home/jimmyrtioms/ros2_ws/install/kitti2bag_ros2/lib/kitti2bag_ros2/kitti2bag \
    odom_color /path/to/kitti/odometry -s 00

# ✅ 實際成功案例 (2011_09_30_drive_0027)
python3 /home/jimmyrtioms/ros2_ws/install/kitti2bag_ros2/lib/kitti2bag_ros2/kitti2bag \
    raw_synced ~/Data -t 2011_09_30 -r 0027
```

#### 方法 B: 使用範例腳本

```bash
cd ~/ros2_ws/src/kitti2bag_ros2
./example_usage.sh
```

## 📁 KITTI 資料集下載

### RAW Dataset
1. 前往 https://www.cvlibs.net/datasets/kitti/raw_data.php
2. 下載以下檔案:
   - `*_sync.zip` (同步數據) - **必需**
   - `*_extract.zip` (高頻 IMU) - **建議**
   - 校準檔案 - **必需**

3. 解壓縮結構:
```
kitti_raw/
├── 2011_09_26/
│   ├── 2011_09_26_drive_0001_sync/
│   ├── 2011_09_26_drive_0001_extract/  (如有下載)
│   └── calib_*
```

### Odometry Dataset
1. 前往 https://www.cvlibs.net/datasets/kitti/eval_odometry.php
2. 下載:
   - `data_odometry_gray.zip` 或 `data_odometry_color.zip`
   - `data_odometry_calib.zip`
   - `data_odometry_poses.zip` (Ground truth, 序列 00-10)

## 📊 輸出 Topics

### RAW Dataset Topics

| Topic | 類型 | 說明 |
|-------|------|------|
| `/imu_raw` | sensor_msgs/Imu | IMU 原始數據 |
| `/imu_correct` | sensor_msgs/Imu | IMU (LIO-SAM 格式) |
| `/gps/fix` | sensor_msgs/NavSatFix | GPS 位置 |
| `/gps/vel` | geometry_msgs/TwistStamped | GPS 速度 |
| `/points_raw` | sensor_msgs/PointCloud2 | Velodyne 點雲 |
| `/tf` | tf2_msgs/TFMessage | 動態座標轉換 |
| `/tf_static` | tf2_msgs/TFMessage | 靜態座標轉換 |
| `/kitti/camera_gray_left/image_raw` | sensor_msgs/Image | 左灰階影像 |
| `/kitti/camera_gray_right/image_raw` | sensor_msgs/Image | 右灰階影像 |
| `/kitti/camera_color_left/image_raw` | sensor_msgs/Image | 左彩色影像 |
| `/kitti/camera_color_right/image_raw` | sensor_msgs/Image | 右彩色影像 |
| `*/camera_info` | sensor_msgs/CameraInfo | 相機校準資訊 |

### Odometry Dataset Topics

| Topic | 類型 | 說明 |
|-------|------|------|
| `/tf` | tf2_msgs/TFMessage | 動態座標轉換 |
| `/kitti/camera_*/image_rect` | sensor_msgs/Image | 已校正影像 |
| `/kitti/camera_*/camera_info` | sensor_msgs/CameraInfo | 相機校準資訊 |

## 🔧 常見使用場景

### 場景 1: 轉換用於 LIO-SAM

```bash
# 1. 轉換資料集
python3 /home/jimmyrtioms/ros2_ws/install/kitti2bag_ros2/lib/kitti2bag_ros2/kitti2bag \
    raw_synced ~/Data -t 2011_09_30 -r 0027

# 2. 播放 bag
ros2 bag play kitti_2011_09_30_drive_0027_synced --loop

# 3. 在另一個終端執行 LIO-SAM
source ~/ros2_ws/install/setup.bash
ros2 launch lio_sam run_kitti.launch.py
```

### 場景 2: 查看轉換結果

```bash
# 查看 bag 資訊
ros2 bag info kitti_2011_09_30_drive_0027_synced

# 播放 bag
ros2 bag play kitti_2011_09_30_drive_0027_synced

# 在另一個終端查看點雲
ros2 run rviz2 rviz2
```

### 場景 3: 批次轉換多個序列

```bash
#!/bin/bash
for seq in 00 01 02 03 04 05; do
    python3 /home/jimmyrtioms/ros2_ws/install/kitti2bag_ros2/lib/kitti2bag_ros2/kitti2bag \
        odom_gray ~/kitti/odometry -s $seq
done
```

## ❓ 常見問題

### Q1: 轉換需要多久時間?
A: 取決於資料集大小：
   - **RAW dataset**: 約 10-15 分鐘
   - **實際案例** (2011_09_30_drive_0027): ~15 分鐘
     - TF 轉換: < 1 秒
     - IMU 數據: 1 秒 (11,556 幀 @ 100Hz)
     - GPS 數據: < 1 秒
     - **Velodyne 點雲: 8:31** (主要耗時)
     - 相機影像: ~36 秒 (4 個相機)
   - **Odometry dataset**: 約 2-5 分鐘

### Q2: 轉換後的 bag 檔案多大?
A: 取決於感測器和資料時長：
   - **實際案例** (2011_09_30_drive_0027, 115.5 秒): **6.0 GB**
   - RAW dataset 平均: 3-7 GB (取決於時長)
   - Odometry dataset (seq 00, 4541 幀): ~1-2 GB

### Q3: 可以只轉換部分感測器嗎?
A: 目前工具會轉換所有可用的感測器資料。如需客製化，請修改原始碼。

### Q4: 為什麼點雲需要 ring 資訊?
A: LIO-SAM 等 SLAM 系統需要 ring channel 來正確處理 Velodyne 點雲。本工具會自動計算。

### Q5: 時間戳正確嗎?
A: RAW dataset 使用原始時間戳，Odometry dataset 使用相對時間加上當前 epoch。

### Q6: 可以用於其他 SLAM 系統嗎?
A: 可以! 輸出的是標準 ROS2 訊息格式,相容所有 ROS2 SLAM 系統。

## 📝 技術細節

### TF 樹結構 (RAW Dataset)

```
world
└── base_link
    └── imu_link
        ├── velodyne
        ├── camera_gray_left
        ├── camera_gray_right
        ├── camera_color_left
        └── camera_color_right
```

### 座標系定義

- `world`: 世界座標系 (OXTS 起始點)
- `base_link`: 車輛基座
- `imu_link`: IMU 座標系
- `velodyne`: LiDAR 座標系
- `camera_*`: 各相機座標系

### 時間同步

- RAW: 所有感測器使用統一的時間戳
- Odometry: 影像使用 `times.txt` 中的時間
